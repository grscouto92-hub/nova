# 🏠 Lar em Dia — Smart Family Workspace & Chore Manager

**Lar em Dia** is an open-source, real-time household chore management web application designed to eliminate domestic mental load through **algorithmic load balancing**, weekly rotation, and real-time family synchronization.

🔗 **Live Demo:** [nova-ten-rose.vercel.app](https://nova-ten-rose.vercel.app)

---

## ✨ Key Features

* **⚖️ Smart Load Balancing:** Automatically distributes household routines across family members by weighing task duration (minutes), physical effort (Levels 1–3), and age restrictions (Adult vs. Child capacity).
* **🔄 Automated Weekly Rotation:** Eligible routines rotate automatically every Sunday so no single person gets stuck with the same chore forever.
* **☁️ Real-Time Cloud Sync + Local Demo Mode:** Powered by Firebase Authentication and Cloud Firestore for instant multi-device updates, with a 1-click Local Demo fallback.
* **🤝 Task Swap Requests:** Family members can reassign tasks or send formal swap requests with custom notes for approval.
* **🏆 Optional Gamification & BI Reports:** Weekly engagement leaderboards, SVG progress rings, individual participation metrics, and an auditable completion log.
* **🛒 Shared Shopping List & Family Noticeboard:** Built-in grocery replenishment list and color-coded sticky notes.
* **📦 Zero-Build & Full Data Portability:** Runs out-of-the-box from a single `index.html` file using Vanilla ES6+ JavaScript, Tailwind CSS, and Lucide Icons. Includes full `.json` backup export and import.
